ОТЧЕТ

Подготовила: Данилина Алина, гр. БМТ2-31М

Проект: печатная плата для усилителя ЭЭГ

1. Библиотека компонентов (сабмодуль)
Создан отдельный git-репозиторий KiCAD-libs, который подключен к основному проекту как git-сабмодуль (папка libs).
В библиотеке собраны УГО и посадочные места для всех компонентов схемы.
Для компонентов добавлены 3D-модели (STEP и STP).

2. Схема электрическая принципиальная
Схема перенесена в KiCad и оформлена с рамкой и основной надписью по ГОСТ.
Для всех компонентов в свойствах заведено и заполнено поле Manufacturer_Part_Number с реальными артикулами (с сайта Чип и Дип).

3. Печатная плата
Выполнена трассировка платы с учетом технологических норм завода «Резонит»
(ширина дорожек 0.2 мм, отверстия 0.4 мм, зазоры 0.15 мм, толщина шрифта 1 мм).
Соблюдены принципы DFMA: шелкография не перекрывает контактные площадки, учтены зазоры паяльной маски, обеспечен теплоотвод для стабилизатора.

4. Скрипт автоматизации
В корне проекта создан файл build.bat, который через утилиту kicad-cli автоматически выполняет:
- Проверку ERC (электрические правила),
- Проверку DRC (правила проектирования платы),
- Генерацию Gerber-файлов,
- Генерацию перечня элементов (BOM) в формате CSV.
- Экспорт схемы в PDF.
Все результаты сохраняются в папку output_files (прикреплена в репозитории, при запуске скрипта обновляется).
